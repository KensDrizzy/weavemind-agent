# Opportunity Scorecard

给每个候选方向按 1-5 分评分，最后用加权总分辅助选择。

| 维度 | 权重 | 评分问题 |
| --- | ---: | --- |
| 用户痛点强度 | 2.0 | 这个问题是否高频、明确、会阻塞用户完成工作？ |
| WeaveMind 契合度 | 2.0 | 是否能复用现有 ReAct、Plan、Multi-Agent、RAG、Web、MCP、微信入口或 Skill 系统？ |
| 可验证性 | 1.5 | 是否能用一次试跑、测试、对比样例或用户提示验证价值？ |
| 差异化 | 1.2 | 是否体现 WeaveMind 的独特组合，而不只是常见助手功能？ |
| 实现复杂度 | -1.0 | 第一版是否会牵涉大量基础设施、账号权限或不稳定外部依赖？ |
| 风险 | -1.0 | 是否有隐私、版权、安全、误导性结论或维护成本风险？ |

## 使用方法

1. 先给每个维度 1-5 分。
2. 加权总分 = 正向维度加权和 - 负向维度加权和。
3. 优先选择总分最高且能在 1-2 个文件内完成第一版的方向。
4. 如果两个方向分数接近，选择更容易通过真实用户提示验证的方向。

## 输出字段

- `方向`：一句话名称。
- `证据`：内部/外部依据。
- `MVP`：第一版最小能力。
- `验收`：用户如何判断它有用。
- `放弃条件`：什么信号说明不值得继续。
